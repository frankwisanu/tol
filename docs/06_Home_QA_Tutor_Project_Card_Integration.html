TrueOnline (TOL) - Automation Testing Standard & E2E Validation

โครงสร้างทดสอบระบบอัตโนมัติระดับองค์กร (Enterprise Automation Testing Standard) สำหรับ TrueOnline (TOL) & FMC Convergence (One App) ครอบคลุมทั้ง 23 โมดูลธุรกิจตามข้อกำหนดจริง: การตรวจสอบพื้นที่โครงข่ายผ่าน SGIS Webview (Green/Yellow/Red), ระบบจับคู่ใบหน้า e-KYC & Biometric Liveness, การผูกสิทธิ์ส่วนลดเบอร์ True/Dtac (xT/xD FMC), การจองคิวช่างติดตั้งแบบ Real-Time, และการส่งคำขอ tolSubmit สู่ระบบ High Level (HL/iOM) พัฒนาตามสถาปัตยกรรม Page Object Model (POM) ใน Robot Framework (.locator, .page, .features) พร้อมเอกสาร BA, PO (Gherkin), BRD/PRD และ Traceability Matrix 100%

  • SGIS Feasibility Engine: คัดกรองคู่สาย FTTH/FTTC พร้อมระบบขออนุมัติค่าทางสายเกิน (TC Approve Flag)
  • Omnichannel Self-KYC: ตรวจสอบสิทธิ์ Fraud TMV และสแกน QR Code ยืนยันตัวตนด้วย Biometric Match ≥ 85%
  • Convergence FMC Matrix: คำนวณส่วนลดคู่สายแบบ Real-Time และยกเว้นค่าแรกเข้า (Waive Entry Fee 890 THB)
  • Company Standard POM: แยกสัดส่วนเลเยอร์ .locator, .page, .features ชัดเจน รองรับการเปิดบน Visual Studio นำเสนอลูกค้าได้ทันที
